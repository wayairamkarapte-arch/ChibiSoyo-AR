ChibiSoyo WebAR タップ修正版

修正内容:
・ARのタップ座標をLive2D Canvasの画面外オフセットを含めて変換
・DPRを二重に計算しないようにCSSピクセル座標を使用
・iOS Safariでも受け取りやすいdocument側でpointerupを監視
・元の位置調整機能、案内表示、モデル、モーションを保持

公開方法:
ZIPを展開し、全ファイル・フォルダをGitHubリポジトリのルートへアップロードしてください。
既存の同名ファイルは更新してください。
今回のコード変更はindex.htmlのみです。index.htmlだけの上書きでも構いません。

注: スマートフォン実機では未検証です。
